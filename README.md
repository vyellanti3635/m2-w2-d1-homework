# m2-w2-d1-homework

Module 2, Week 2, Day 1 homework (GAP Week 6 Day 1): convert a page to responsive.

## Note on the starter files

The two homework files on GAP, `wk2-day1-homework.zip` and `end-day1-homework.zip`, were empty when I downloaded them.
Because of that, I did this homework on the home page (`index.html`) of the in-class demo site from Module 1 instead of the provided page.

## What was made responsive

1. The main area
   - stacks at less than 600px
   - displays 2 columns at 600px or higher
   - the image is responsive
2. The header background image is responsive

The changes are in `index.html` and `style.css`. The other pages are included only so the navigation links work.
